
# Student Academic Management System

## Python Internship – Phase 03

### Project Overview
The Student Academic Management System is a Python desktop
application developed using Tkinter and SQLite.

It allows users to manage student academic information through
a graphical user interface.

### Technologies Used
- Python 3
- Tkinter
- SQLite
- VS Code
- Git and GitHub

### Features
- Add student records
- View all students
- Search students by roll number
- Update student details and marks
- Delete student records with confirmation
- Calculate total, average and grade
- Validate student details and marks
- Responsive GUI with scrollbars
- Persistent SQLite database

### Project Files
- main.py – Graphical user interface
- database.py – Database creation
- student_operations.py – Student management functions
- students.db – Local SQLite database (generated automatically)

### How to Run

1. Install Python 3 with Tkinter support.
2. Open a terminal in the repository's root folder.
3. Run:

   py Phase3/main.py

Alternatively, open the Phase3 folder and run:

   py main.py

The application creates its database automatically if required.
